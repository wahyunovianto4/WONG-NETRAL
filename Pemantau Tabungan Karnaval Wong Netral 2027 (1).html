Petunjuk konfigurasi & akses baca saja (untuk administrator)

Sumber data. Sheet Tabungan 2027: kolom No, Nama Anggota, M1–M5 + Total per bulan (Oktober–September), Total Setahun, Target Setahun. Total tabungan dihitung ulang dari isian mingguan; target diambil dari Target Setahun. Sheet Pengeluaran (opsional) dibaca jika punya kolom Nama (atau No) dan Nominal/Jumlah; jika tidak ada, pengeluaran dianggap Rp 0.

Konfigurasi. CONFIG.SHEET_ID, SHEET_TABUNGAN, SHEET_PENGELUARAN ada di awal skrip dan hanya bisa diubah administrator. Pengguna tidak memiliki menu untuk mengubahnya.

Akses baca saja. Aplikasi hanya memakai permintaan GET (ekspor CSV), tanpa API key/token dan tanpa fungsi tulis. Di Google Sheets: Bagikan → “Siapa saja yang memiliki link” → Pelihat. Jangan beri akses Editor.

Data pribadi. Link Pelihat berarti siapa pun yang memegang link dapat membaca sheet. Untuk data sensitif gunakan Apps Script doGet saja atau backend dengan scope spreadsheets.readonly.

Penerapan. Pratinjau Claude memblokir permintaan ke situs lain. Unggah file ini ke hosting sendiri (GitHub Pages/Netlify) agar terhubung ke spreadsheet.
